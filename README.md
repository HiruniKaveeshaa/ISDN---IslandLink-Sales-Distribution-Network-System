# 🔗 IslandLink Sales Distribution Network

A centralized sales distribution management system developed to streamline order processing, inventory management, delivery coordination, billing, payments, and management reporting.

## ✨ Key Features

- 📦 Centralized order management
- 📊 Inventory synchronization
- 🚚 Delivery scheduling and tracking
- 💳 Billing and payment management
- 📈 Management dashboards and reporting
- 🔐 Role-based access control
- 👥 User authentication and authorization

- MongoDB
- JWT

## 🏗️ Architecture

- Application / Business Logic Layer
- Data Layer
